# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Report them privately through
GitHub: **Security → Report a vulnerability** on this repository
(<https://github.com/xTudoS/dual-audio/security/advisories/new>).

Useful details: affected version (see the APK name or *Settings → Apps → Dual Audio*), Android
version and device, and steps to reproduce.

## Verifying downloads

Only install APKs from this repository's [Releases](https://github.com/xTudoS/dual-audio/releases).
Each release includes a `SHA256SUMS.txt`, and every release is signed with the same key. Android
refuses to update the app from an APK signed with a different key.
